# Minecraft Texture: ButterflyFanMinecraft

ButterflyFanMinecraft is a 64 × 64 Minecraft skin texture atlas in SVG format, featuring monarch-inspired orange-and-black wings on the back, paired antennae, and a green “I love Minecraft” shirt design.

## Install

1. Download `assets/textures/monarch_butterfly_skin.svg` from the project.
2. Open the SVG in an image editor that can export SVG files as PNG.
3. Export it as a 64 × 64 PNG, preserving the pixel-art edges and transparency.
4. Upload the PNG as a player skin using the skin options for your Minecraft edition.

## Use

1. Preview the exported PNG in a Minecraft skin viewer or editor.
2. If needed, adjust the texture in a skin editor that supports 64 × 64 skin atlases.
3. Apply the PNG through your Minecraft skin settings and check the back view to see the wings.
